# Læsevenlig udgave

Vælg **Læsevenlig udgave** øverst i en gemt konsekvensanalyse eller ved den
enkelte version under sagens **Vurderinger**. Valget følger linket som
`view=readable`, så samme overblik kan åbnes igen. **Fuld vurdering** viser alle
afsnit og kildehenvisninger.

Overblikket samler konklusion, menneskelig beslutning, mangler, afklaringer,
kildegrundlagets forbehold og næste skridt. Kendte fagbegreber får korte danske
forklaringer ved siden af den gemte tekst. De tre højest prioriterede risici
vises med begrundelse og forslag til at begrænse risikoen. Alle risici kan åbnes
i den fulde vurdering. Anbefalinger står særskilt.

Visningen laver ingen nye modelkald, ændrer ingen risikoscorer og registrerer
ingen godkendelse. Alle blokerende forhold og afklaringer forbliver tilgængelige
via udfoldning. Tidligere JEV-kontrol af ændrede afsnit tælles ikke som aktuel.
Den læsevenlige udgave gælder også historiske vurderinger.

Den anvendte model vises med sit registrerede navn, eksempelvis **GPT-5.6 Sol**
eller **GPT-6 Astra**. Kendte noter om udviklingsplatformen vises neutralt.
Originale kilder, vurderingstekster og internt revisionsspor bevares.

Downloadknapperne nederst henter den **fulde** konsekvensanalyse i Word og
risikovurderingen i Excel. Eksporterne viser også modelnavnet uden platformtag.
